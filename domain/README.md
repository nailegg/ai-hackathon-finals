## 카드 선택 규칙

1. **고르는 것은 P0다.** 계약 초안을 다 쓴 뒤 `CARD_INDEX.md`만 보고 §10 "참고 카드 제안" 줄에 `S0n` 또는 `없음`과 차이 3개(입력 단위·산출물·채점 방식)를 적는다. 사람이 고르지 않는 이유: 비교 기준은 전부 CONTRACT에 이미 있고, 카드를 먼저 공부한 사람이 README를 카드에 끼워 맞추는 것이 가장 흔한 실수다.
2. **후보의 기준은 색인에 있다.** 입력 형식(표·텍스트·이미지·코드)과 산출물이 둘 다 같을 때만 후보다. 차이 3개 중 하나라도 AC1이나 채점 방식을 바꾸면 `없음`이다.
3. **사람은 받아들일지만 정한다.** 질문은 하나, "그 카드의 Baseline을 이 과제에 그대로 써도 되는가". 색인에는 Baseline이 없어 사람만 답할 수 있다. 기억나지 않으면 주지 않는다. `없음`이면 다른 카드를 찾지 않는다.
4. 주는 것은 카드 원본이 아니라 Baseline·독립 검증·KPI·함정 절의 발췌(`CARD_REF.md`)다. 그 안의 숫자·상태명·컬럼명도 예시이며, 실제 값은 README와 데이터가 정한다.

카드를 고치거나 추가하면 `CARD_INDEX.md`의 해당 줄도 같이 고친다.
