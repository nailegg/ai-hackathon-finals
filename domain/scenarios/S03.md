## 가상 출제문
"공정 센서와 일부 계측 결과로 검사되지 않은 Wafer의 품질 지표를 추정하고, 불확실한 예측 또는 이상 설비를 식별하는 도구를 작성하시오. 제출은 `sample_submission.csv` 형식."

## 예상 데이터

## 사용자·역할 (웹이면)
엔지니어: 예측 조회·OOD 경보 확인. 관리자: 모델 재학습 실행. 결과 파일 과제면 역할 없음.

## Baseline
1. 타깃·제출 스키마 확인(§2). `time_split`로 시간/그룹(Lot) 분할, 같은 Lot이 양쪽에 들어가지 않게.
2. baseline: 전체 평균, 같은 Recipe 평균. 이것부터 제출 파일 생성.
3. Ridge 또는 HistGradientBoosting(가능하면) → MAE/RMSE를 baseline과 같은 분할에서 비교.
4. Tool·Recipe별 성능표, 예측 구간(잔차 분위수)으로 불확실성 표시.

## 독립 검증
- 제출 파일 행 수·ID·컬럼이 sample과 일치. 결측 예측 0.
- 타깃 파생 컬럼이 feature에 없음(상관 1.0 컬럼 탐지).
- 같은 Lot이 train/valid에 동시에 없음.

## KPI
MAE, RMSE, 그룹별 worst-case MAE, Spec 이탈 예측 정확도, 실행 시간.

## 함정
Lot 단위 누수, 측정 후 생성된 값 사용, test 라벨을 전처리에서 참조, 범주형 ID를 숫자로 그대로 학습, 검증 데이터 없이 재학습 안 하고 제출.

## 화면 3개
1. 예측 vs 실측 산점도 + 지표표.
2. Tool·Recipe별 오차표, OOD 경보.
3. 제출 파일 다운로드와 재현 명령.
