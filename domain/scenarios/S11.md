## 가상 출제문
"웨이퍼 테스트 결과를 Die 단위 양/불 격자(웨이퍼맵)로 제공한다. 일부에는 결함 패턴 라벨이 있다. 라벨 없는 웨이퍼의 패턴을 분류하고, 패턴별 발생 추이와 의심 설비를 보고하는 도구를 만드시오."

## 사용자·역할
결과 파일 과제가 기본. 웹이면 엔지니어(조회), 관리자(라벨 수정·확정) 2역할.

## Baseline
1. 격자를 읽어 **손으로 만든 특성**: 불량 비율, 중심/가장자리 불량 비율(반경 구간 3~5개), 각도 구간별 불량 비율(8~12개), 가장 큰 연결 성분 크기·길이, 행·열 투영의 분산. 모두 numpy 없이도 계산 가능.
2. 분류기: sklearn이 있으면 RandomForest/HistGradientBoosting, 없으면 kNN(거리) 또는 규칙(중심 비율 > 임계 → Center, 가장자리 비율 > 임계 → Edge-Ring 등).
3. 다수 클래스(데이터에서 센 값. 예: None) 예측이 첫 제출 파일. 클래스 불균형이 심하므로 macro-F1을 함께 본다.
4. 설비 연결은 `wafer_meta`로 패턴별 Tool 분포를 `group_compare`.

## 독립 검증
- 제출 파일의 `wafer_id` 집합·순서가 sample과 같고 pattern 값이 허용 집합 안에 있음.
- 같은 Lot의 웨이퍼가 train/valid에 섞이지 않음(`time_split`의 group_split).
- 격자 크기가 섞여 있으면 특성이 크기에 불변인지 작은 테스트(면적·길이 같은 크기 특성은 격자 크기로 나눠 정규화하고, 같은 맵을 2배 확대해도 값이 같은지 확인).

## KPI
macro-F1, 클래스별 recall(희소 패턴 Scratch·Donut), 혼동행렬, 처리 시간.

## 함정
Accuracy만 보기(None이 80% 이상), 격자 크기 불일치, 0(없음)과 1(양품)을 혼동, 라벨 없는 데이터를 "None"으로 가정, 이미지 모델 설치에 시간 소모, 회전·반전 대칭을 무시한 특성.
