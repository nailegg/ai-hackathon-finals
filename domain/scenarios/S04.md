## 가상 출제문
"여러 Lot, 공정별 적격 설비, 가용 시간, 정비 일정, 납기가 주어진다. 기존 계획보다 납기 지연을 줄이는 실행 가능한 스케줄을 만들고, 설비 장애 시 재계획하시오."

## Baseline
1. 파서 → 분 단위 정수로 정규화 → `validate_schedule`을 **먼저** 작성.
2. `greedy_assign`: 디스패칭 규칙(EDD 또는 CR)로 Lot 순서, Step마다 가장 빨리 비는 적격 설비 배정, 정비 구간 회피.
3. KPI 계산 → baseline_schedule과 비교표.
4. 시간이 남으면 CP-SAT(설치 가능할 때) 또는 local search(두 작업 교환) 개선. 타임아웃 시 greedy 결과 반환.

## 독립 검증
- 선후 관계: 같은 Lot의 step k+1 시작 ≥ step k 종료.
- 설비 겹침 없음, 적격 설비만 사용, 정비 구간과 겹치지 않음, release 이전 시작 없음.
- 모든 Lot·Step이 스케줄에 한 번씩 존재.
- 의도적으로 충돌을 넣은 fixture에서 validator가 실패하는지.

## KPI
hard 위반 0건(필수), total/weighted tardiness, makespan, 지연 Lot 수, 계산 시간, 재계획 시 변경 작업 수.

## 함정
시간 단위 혼용, 적격성 미검증, 선후 위반, 정비 침범, Lot 누락, 목적함수 가중치 임의 변경, 솔버 설치에 30분 소모.

## 화면 3개
1. 스케줄 실행(파라미터: 규칙, 시나리오) + KPI 비교 카드.
2. Gantt(설비 행 × 시간) 또는 표(설비별 작업 순서).
3. 장애 what-if: 설비 선택 → 재계획 → 변경 diff.
