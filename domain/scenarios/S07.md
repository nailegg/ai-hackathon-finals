"설비별 PM 주기·마지막 PM 일자·고장 이력, 정비 인력의 근무표와 역량, 부품 재고와 리드타임, 생산 계획이 주어진다. 생산 영향을 최소화하면서 PM 기한을 지키고 부품 결품이 없는 주간 정비 일정을 세우고, 담당자가 승인·조정하는 웹 서비스를 만드시오."

## Baseline
1. PM due = last_pm + cycle. 주기 단위(일 / Wafer 수 / 가동시간)는 README·데이터로 확인하고 단위별로 due를 따로 계산한다. 기한 임박·criticality 순으로 정렬(EDD).
2. `greedy_assign`: 날짜·교대 슬롯에 기술자(skill 일치, 가용시간)와 부품(재고 ≥ 소요) 확인 후 배정. 생산 계획 시간이 적은 슬롯 우선.
3. 부품 부족이면 발주 제안(리드타임 반영) 생성, 일정은 입고 이후로.
4. KPI: 기한 초과 PM 수, 생산 손실 시간, 결품 건수.

## 독립 검증 (`validate_schedule` 변형)
- 기술자 시간 겹침 없음, skill 불일치 0, 가용시간 초과 0.
- 같은 Tool 동시 정비 없음, 부품 소요 ≤ 재고(+입고), 기한 초과는 목록화.
- 모든 due PM이 일정에 있거나 "미배정 사유"에 있음.

## KPI
PM 준수율, 기한 초과 일수 합, 생산 손실 시간, 결품 0, 기술자 가동 균형.

## 함정
PM 주기가 일·Wafer 수 혼재, `down_end` 결측(진행 중), parts_used 문자열 분리, 교대 경계 넘는 작업, 발주 리드타임 무시.

## 화면 3개
1. 주간 정비 보드(날짜×기술자 또는 날짜×설비), 기한 임박 강조.
2. 작업 상세: 부품 소요·재고, 승인/조정 버튼.
3. 부품 재고·발주 제안 목록(승인 흐름).
