## 사용자·역할 (웹이면)
연구원: 후보 추천 실행·근거 열람·선택. 관리자: 예산·제약 설정. 결과 파일 과제면 역할 없음.

## Baseline
1. 제약 필터(범위, 금지 조합, 이미 수행한 조건 제외) → feasible 후보.
2. baseline 추천: 기존 최고 품질 조건과 가장 가까운 후보(kNN, 거리 기반).
3. surrogate: Ridge 또는 RandomForest로 품질 예측 + 불확실성 대리(잔차 분위수, kNN 거리).
4. 점수 = 예측 품질 + λ×불확실성 − 비용 페널티 → 예산 내 greedy 선택(다양성: 같은 영역 중복 제한).

## 독립 검증
- 추천 후보 모두 제약 만족, 예산 합 ≤ max_budget, 개수 ≤ max_trials.
- 이미 실험한 조건 재추천 0건.
- 범주형(`material`) 인코딩 후 역변환 확인.

## KPI
제약 위반 0, 예산 준수, holdout에서 surrogate MAE, 추천 집합의 예측 품질·다양성, 재현성(seed).

## 함정
외삽(범위 밖 예측을 믿음), 점추정만 사용, 범주형을 숫자로 취급, 이미 한 실험 반복, 예산 초과.

## 화면 3개
1. 추천 후보 표(예측 품질, 불확실성, 비용, 선정 이유).
2. 조건 공간 산점도(기존 실험 vs 추천).
3. 예산·제약 입력과 재추천.

## 쓸 snippets와 shape

## 330분 우선순위
- **MVP**: 제약 필터 → kNN baseline → 회귀 → 예산 내 정렬 추천 + 근거.
- **가산점**: 불확실성 탐색, 다양성, 배치 순차 선택, 예산 민감도.
