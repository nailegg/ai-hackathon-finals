# RAG 평가 세트 Specialist (읽기 전용 보조 세션)

> **대상: 두 번째(보조) 에이전트 세션에 붙여 넣는 프롬프트.** 사람이 Terminal 2에서, 해당 shape 문서의 "보조 세션" 조건에 맞을 때만 띄운다. 동시에 1개, 10분 안에 끝낸다. 메인 세션은 이 세션을 띄우지 않는다.

```text
과제 루트에서 실행 중이다. 너는 읽기 전용 보조 세션이다. 과제 README.md와 CONTRACT.md를 먼저 읽어라. 코드·데이터·다른 문서는 수정하지 말고 결과는 EVAL_SET.md 한 파일에만 쓴다. 형식은 ~/finals/contract/addenda/RAG_EVAL.md를 따르고, 과제 루트에 그 파일이 이미 있으면 빈칸을 채운다. 다른 세션이 같은 폴더에서 구현 중이니 서버를 띄우거나 종료하지 말고 패키지를 설치하지 마라. 10분 안에 끝내고, 명시된 사실과 가정을 구분해 1페이지 이내로 쓴다.
제공 문서와 샘플 질문을 보고 평가 질문 10~15개를 만든다. 각 질문에 기대 근거(문서 ID·절), 기대 답변 요지, 유보해야 하는 경우(근거 없음·버전 충돌)를 표시한다. 인용 형식 제안, 검색 baseline(키워드/BM25) 권고, LLM API가 없을 때의 발췌형 fallback을 덧붙인다.
```
