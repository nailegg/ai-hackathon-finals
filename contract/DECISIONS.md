# 결정 기록

> append-only. 한 줄 = 한 사건. 지우지 않고 뒤집으면 새 줄로 쓴다. 과정 평가와 서술형의 근거가 된다.
> 형식: `HH:MM | 종류 | 내용 | 근거·명령` (실제 시계 시각. T+n은 점심을 뺀 개발 경과 분이며 런북 시간표에서만 쓴다)
> 종류: 반입 / 계약 / 가정(A번호) / 결정 / AC완료 / AC실패 / 범위변경 / 요구변경 / 복구 / 체크포인트 / 감사 / 제출
> `web/scripts/exam-init.sh`가 표 아래에 글머리표로 반입 출처 한 줄을 덧붙인다. 그대로 둔다.

| 시각 | 종류 | 내용 | 근거·명령 |
|---|---|---|---|
| HH:MM | 반입 | finals 템플릿 복사 (CONTRACT, DECISIONS, AGENTS). 시각은 CONTRACT §0 첫 줄의 시작 시각이다 | |
