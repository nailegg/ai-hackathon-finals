# 체크 문제 10

> 답은 본인 말로. 아래 "답 스케치"는 채점 기준이 아니라 빠뜨리면 안 되는 포인트다.

1. **수율이 특정 Tool에서 97%→92%로 떨어졌다. Tool이 원인이라고 바로 말하면 왜 위험한가?**
   스케치: 제품·Recipe mix 변화, 시간 효과, 상류 공정 영향, 표본 수. 같은 Recipe의 다른 Tool과 비교(matched cohort), 변화 시점 전후 비교. "원인 후보"와 "확정 원인"을 구분.

2. **전체 불량률 0.5%에서 Accuracy 99.5% 모델이 쓸모없을 수 있는 이유와 대신 보여줄 것은?**
   스케치: 다수 클래스 예측만 해도 99.5%. PR-AUC, Recall@K, 혼동행렬, 경보당 적중률.

3. **동일 Lot의 2번 공정이 1번보다 먼저 시작할 수 없고 설비는 겹칠 수 없다. 결과 JSON만 보고 어떻게 검사하나?**
   스케치: Lot별 step 순서대로 start ≥ 이전 end; Tool별 구간 정렬 후 인접 구간 겹침 검사; 적격 설비 목록 대조; 정비 구간 침범; release 이전 시작. 계산 코드와 분리된 함수.

4. **OEE의 세 구성요소와 각각의 분모·분자는?**
   스케치: 가동률 = 가동시간/계획시간, 성능 = 실제 생산량/(가동시간×이론속도), 품질 = 양품/총생산. 곱.

5. **MTBF와 MTTR의 차이, 그리고 Availability는?**
   스케치: MTBF = 가동시간 합/고장 횟수, MTTR = 수리시간 합/고장 횟수, Availability = MTBF/(MTBF+MTTR).

6. **lot_history(1 Lot : N wafer)와 inspection(Lot 단위)을 조인해 양품 수를 합하면 무엇이 잘못되나?**
   스케치: 1:N 조인 후 Lot 값이 wafer 수만큼 복제되어 과대합계. 집계 단위를 먼저 맞추거나 distinct 후 합산. 조인 전후 행 수 확인.

7. **시간 누수란 무엇이고 어떤 컬럼이 의심스러운가?**
   스케치: 예측 시점 이후 생성된 값(검사 결과, 조치 이력, 최종 상태). 시간순 분할, 같은 Lot이 train/valid 양쪽에 있지 않게 그룹 분할. 타깃과 상관 1.0인 컬럼.

8. **매뉴얼에 없는 조치를 AI가 확신하며 제안한다. 무엇을 해야 하나?**
   스케치: 근거 없음 표시 또는 유보, 자동 실행 금지, 제안→승인→실행 분리, 감사 로그, 문서 속 지시문은 데이터.

9. **OHT 반송 배차나 통근버스 배정 같은 문제에서 20분 안에 만들 baseline과 그 검증은?**
   스케치: 용량 고려 greedy(우선순위·최근접·EDD), 독립 validator(용량 초과 0, 미배정 0, 시간창), KPI(총 거리·지연) baseline 기록. 이후 swap/2-opt 1개.

10. **하이닉스가 공개한 자율형 팹의 3축과 각각에 대응하는 과제 형태는?**
    스케치: Operational AI(설비 보전·결함 분석 → 이상 분석·보전 일정), Physical AI(OHT·AMR·로봇 → 반송 배차·물류), Digital Twin(Omniverse → 시뮬레이션·what-if). 플러스 GaiA(SOP·지식 에이전트), MADA(센서·수율 통합 대시보드).
